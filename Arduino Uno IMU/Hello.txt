This Is the IMU Variant Of the Arduino Uno Compatible Board. I've Added an MPU-6050 IC On the Bottom Layer With Appropriate level Shifting and the Design Is hopefully Ready To use. Interrupt Functionality Is Unavailable, but the Normal I2C Operation Is Available, at 0x68 Address. Use The Appropriate Arduino Libraries to run the MPU.
